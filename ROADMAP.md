# NEXUS Roadmap

## After the hackathon

- Collect judge and user feedback and rank work by demonstrated user value.
- Add a small evaluation set for planner routing, extraction failures, quiz formatting, and synthesis honesty.
- Add source citations/retrieval only if actual document sizes exceed the current context budget.
- Consider OCR for scanned PDFs only if users need it; expose OCR uncertainty.
- Add history or persistence only with a clear user-consent and retention policy.
- Add usage limits and cost/latency visibility before widening access.
- Defer web search, external actions, and multi-agent orchestration until a concrete use case warrants the complexity.
